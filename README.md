# Student Marks Prediction Using Machine Learning

## Project Overview
This beginner-level machine learning project predicts student exam marks based on the number of study hours using Python and Linear Regression.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Create a sample dataset.
2. Explore and visualize the data.
3. Split data into training and testing sets.
4. Train a Linear Regression model.
5. Evaluate predictions using MAE and R-squared.
6. Predict marks for new study-hour inputs.

## How to Run
1. Install the required Python libraries.
2. Open the notebook in Jupyter Notebook or JupyterLab.
3. Run the cells in order.

## Disclaimer
This project uses illustrative sample data for educational purposes. Predictions are not a guarantee of actual academic performance.
